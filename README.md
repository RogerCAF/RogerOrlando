# Roger Orlando — Personal website

Premium dark-mode portfolio van Roger Chjin A Foeng. De website combineert grafisch design en IT met een interactieve playground en een verborgen terminal.

## Stack
Next.js App Router · React 19 · TypeScript · CSS · Lucide icons

## Development
```bash
npm install
npm run dev
npm run build
```

## Deploy
Importeer `RogerCAF/RogerOrlando` als Next.js-project in Vercel. Voeg `rogerorlando.nl` en `www.rogerorlando.nl` toe onder **Settings → Domains**. Stel bij Theory7 uitsluitend de DNS-records in die Vercel aangeeft.

Let op: de domeinkoppeling en publicatie op Vercel moeten nog worden uitgevoerd. De weergegeven apps zijn persoonlijke projecten of prototypes; projectbeschrijvingen zijn geen verklaring dat alle functies publiek beschikbaar zijn.
